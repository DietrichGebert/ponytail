## 推送踩坑记录（已解决）

- 症状：`git push` 挂起不返回（180s 无输出被 kill）。
- 根因：本机 Git Credential Manager 里存的 GitHub 账号是 `chenhhaa`（**8 个字符**），
  而仓库属主是 `chenhhaaa`（**9 个字符**），两个不同账号 → 403 `Permission denied`。
  交互模式下 GCM 反复重试授权，所以表现为卡死。
  诊断手法：`GIT_TERMINAL_PROMPT=0 GCM_INTERACTIVE=never git push origin main` 让错误直接暴露。
  修复：`git credential-manager github logout chenhhaa` 清掉错误凭据，再 push 重新登录正确的 `chenhhaaa`。
- 注意：`git ls-remote origin` 成功**不能**证明认证正常——公开仓库匿名可读，只验证了网络。
- `.workbuddy/` 未加入 .gitignore（仓库原有 .gitignore 没这条），会被 git status 显示为未跟踪；
  提醒过用户，未擅自改动。
