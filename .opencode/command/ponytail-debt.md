description: "Harvest shortcut: comments into a tracked debt ledger"
---

Harvest `shortcut:` source notes (and older `ponytail:` ones) into a debt ledger. Honor project guidance choosing another marker, no marker, or tracker-only records; a scan never adds markers. Find candidate text with `git grep --no-index --exclude-standard -nF -e 'shortcut:' -e 'ponytail:'`, skipping .git and everything .gitignore ignores. For a custom marker word, supply the word without a trailing colon as the marker environment variable through the host tool API or safe shell quoting; never paste user text into shell program text. Use `git grep --no-index --exclude-standard -nF -e "$marker:"` instead; it adds the colon once and treats regex metacharacters literally. Exit 1 means no candidates; report other nonzero exits as scan failures. Read each candidate's enclosing source, including documentation openers, continuation lines and docstrings. Exclude illustrative prose/examples, ordinary string data and non-deferrals such as keyboard-shortcut explanations. Read wrapped text before deciding a trigger is missing; grep is not a language parser. One row per inspected debt marker, grouped by file: <file>:<line>, <what was simplified>. ceiling: <the limit named in the complete source note>. upgrade: <the trigger to revisit>. Tag an inspected record with no upgrade path or trigger as no-trigger. End with the count of markers and how many lack a trigger. If none: 'No local shortcut debt markers found.' This makes no claim about project-wide or tracker debt. Report only, change nothing.
